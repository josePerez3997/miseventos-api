# Mis Eventos API

Backend para la plataforma de gestión de eventos "Mis Eventos".

## Requisitos

- Python 3.12+
- Poetry (gestión de dependencias)
- PostgreSQL

## Instalación

1. Clonar este repositorio:
git clone (https://github.com/josePerez3997/miseventos-api)

2. Instalar dependencias con Poetry:
poetry install

3. Configurar variables de entorno:
cp .env
